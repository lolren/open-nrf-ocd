# nrf_ocd v0.3.4 changes

## USB and HID reliability

- Harden CMSIS-DAP HID report-descriptor parsing against malformed and
  truncated descriptors, with focused regression tests.
- Correct Linux, macOS, Windows, and libusb transport cleanup, descriptor,
  interface-selection, and bounds-handling paths.
- Avoid duplicate libusb device matches and make probe identity handling
  consistently bounded and NUL-terminated.

## Flash and platform support

- Harden nRF54L and nRF54LM20A target detection and flash-algorithm bounds.
- Correct portability issues across Linux x86-64, Linux ARM64/ARMHF, and
  Windows AMD64/i386 builds.
- Remove the obsolete checked-in Windows executable; release binaries are now
  generated by the checksummed release script.

## Release and licensing

- Pin libusb 1.0.27 for reproducible core builds and strip release binaries.
- Add complete license, third-party attribution, source-provenance, and LGPL
  relinking materials.
- Add a corrective source-compliance bundle generator for the existing
  `v0.3.3` Linux x86-64 assets without changing their tag or binaries.
